# ApplyFlow

**Your internship search, organized.**

ApplyFlow is an early-stage, student-focused product concept for managing internship applications, recruiter relationships, deadlines, and next actions. We are validating the problem before committing to a feature set or building an MVP.

## Current stage
**Phase 1 — Customer discovery.** No production application or validated outcomes yet.

## Product documentation
- [Product brief](docs/product-brief.md) — vision, target users, hypotheses, initial scope, and $0 constraints.
- [Customer discovery plan](docs/customer-discovery.md) — interview guide, sampling approach, synthesis, and validation gates.

## Working principles
- Solve a demonstrated student problem before adding features.
- Start with a $0, mobile-friendly web experience.
- Avoid paid APIs, scraping, auto-applying, and unnecessary integrations in the initial MVP.
- Protect research participants and user data; publish only anonymized findings.
- Clearly label targets and hypotheses separately from measured outcomes.

## Status
Research and product definition in progress. Built by an independent student developer. Contributions and feature priorities will be evaluated after initial user interviews.
